Select the live provider for this business. Retell credentials are sent directly to the protected TWIGA server and stored in Supabase Vault. They are never saved in this browser or Android APK.

This is the AI provider's inbound phone number. For Retell, choose a number attached to the linked Retell agent. For Vapi, enter the Vapi phone number assigned to its assistant. The Android phone places it as a second SIM call and attempts to merge both calls using carrier conference support; this requires carrier support.
